# ПРАВИЛО

Логическая игра. Cлова раскрашены по скрытому правилу. Нужно разгадать правило и раскрасить новое слово так же.

MVP: 21 уровень, без бэкенда и аккаунтов, прогресс хранится в `localStorage`.

## Файлы

- `index.html` — интерфейс игры
- `levels.js` — правила, уровни и валидатор
- `validate.js` — проверка уровней из командной строки

## Как добавить уровень

Уровень задаётся только словами и названием правила. Цвета вычисляются кодом, вручную их не вводят:

```js
{ id: 22, title: "Название", rule: "vowels",
  examples: ["СЛОВО", "ЕЩЁ"], question: ["ТЕСТ"],
  explain: "Объяснение после решения.",
  hints: ["Подсказка 1", "Подсказка 2", "Подсказка 3"] }
```

После изменений запустите проверку:

```
node validate.js      # кратко
node validate.js -v   # с раскраской всех слов
```

Валидатор прогоняет примеры через все правила-кандидаты. Если другое правило тоже объясняет примеры, но даёт другой ответ, уровень помечается как проблемный. Тот же отчёт есть в игре: «Настройки → Проверка правил».

## Статистика тестеров

«Настройки → Скопировать статистику» копирует JSON: попытки, подсказки и время по уровням, число сессий и дни активности.
